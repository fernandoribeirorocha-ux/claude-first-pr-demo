# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a practice repository for learning the full GitHub contribution workflow with Claude Code: creating a branch, making a change, committing, and opening a Pull Request. It currently contains no application code — only a `README.md`. There are no build, lint, or test commands, since there is nothing to build, lint, or test.

## Repository structure

- `main` — the base branch
- `fix/readme-typo-and-structure` — an example contribution branch, already merged into the workflow described in the README (fix typos/accents and improve structure)

## Contribution workflow (per README.md)

1. Create a branch from `main`.
2. Make your change.
3. Open a Pull Request describing what changed and why.

Commit messages and README content in this repo are written in Portuguese.
