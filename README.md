# claude-first-pr-demo

Repositório de prática para o primeiro Pull Request feito com Claude Code.

## Objetivo

Este repositório serve como ambiente de testes para praticar o fluxo
completo de contribuição via GitHub: criar uma branch, fazer uma alteração,
commitar e abrir um Pull Request.

## Como contribuir

1. Crie uma branch a partir de `main`.
2. Faça sua alteração.
3. Abra um Pull Request descrevendo o que mudou e por quê.
